# LLM Gateway

A modular LLM gateway for routing requests across AI providers, normalizing streaming responses, and handling failures with fallback and mid-stream recovery.

## Project Structure

- `backend/` — Core gateway API and routing logic
- `frontend/` — Gateway monitoring dashboard
- `demo-app/` — Chat application that consumes the gateway
- `experiments/` — Routing and recovery evaluations
- `docs/` — Architecture and design documentation
- `scripts/` — Development and experiment utilities
